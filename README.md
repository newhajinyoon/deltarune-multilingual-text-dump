# Undertale & Deltarune Multilingual Text Dump

A comprehensive multilingual dialogue explorer for Undertale, Deltarune, and related projects.

## About this project
This project is a heavily modified and almost completely overhauled version of [HushBugger/hushbugger.github.io](https://github.com/HushBugger/hushbugger.github.io). 

## Supported Games & Languages
